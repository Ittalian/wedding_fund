# 貯金目標設定の更新完了

ご要望いただいたUIとロジックの変更がすべて完了しました。

## 実装した変更点

### 1. `BasicInfoScreen` (基本情報管理画面)の整理
- **テキストボックスの完全廃止**: 「必要な貯金目標額」という概念をシステム全体から削除し、画面上のテキストボックスも廃止しました。
- **チェックボックスの完全廃止**: 「常に目標額を貯金（または貯金目標設定を有効化）」というチェックボックスのUIおよび内部フラグ（`alwaysKeepSavingsGoal`）を完全に削除しました。
- **UIの改善**: 「貯金詳細設定」ボタンを廃止し、代わりに画面幅いっぱいの「各費用の支払い後貯金目標を設定する」というわかりやすいボタンに置き換えました。

### 2. `SavingsDetailScreen` (貯金目標設定画面)の変更
- **画面名の変更**: タイトルを「貯金詳細設定」から「貯金目標設定」に変更しました。
- **目標額のデフォルト設定**: 「必要な貯金目標額」の項目を削除し、各費用の「支払い後貯金額」が未入力の場合は一律で ¥0 として扱うように説明文とヒントテキストを修正しました。

### 3. 計算ロジックの変更 (`app_state_provider.dart`)
- 有効/無効のチェックボックスがなくなったため、設定された各費用の「支払い後貯金額」は **常に** 各費用の支払い後に残すべき残高（`minBalance`）として計算されるようにロジックを改修しました。（未設定の場合は ¥0）

### 4. 提案メッセージの修正 (`HomeScreen`)
- 支払い後貯金額の改善提案時に表示される確認ダイアログのメッセージから不要な改行を削除し、「『〇〇』の支払い後貯金額を ¥X から ¥Y に変更しますか？」と1行にすっきりと表示されるようにしました。

## 確認事項
アプリをビルドして実行し、以下の点をご確認ください：
1. 基本情報管理画面にチェックボックスがなくなり、「各費用の支払い後貯金目標を設定する」という横長のボタンが表示されていること
2. 貯金目標設定画面にて、「必要な貯金目標額」の項目が消え、各費用の個別設定が0として扱われる説明になっていること
3. 支払い後貯金額を設定した際、出費額計算や時期計算の提案にその金額が自動で反映されること
4. ホーム画面からの「支払い後貯金額の見直し」提案をタップした際のダイアログの表示が改行されずに見やすくなっていること
